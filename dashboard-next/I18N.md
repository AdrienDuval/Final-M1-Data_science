# Internationalization (i18n)

The dashboard uses **[next-intl](https://next-intl.dev/)** for English and French, with a **language switcher** in the top navigation (EN | FR).

## How it works

- **No URL change** — locale is stored in a cookie (`locale=en` or `locale=fr`) and applied on the next page refresh.
- **Message files** — `messages/en.json` and `messages/fr.json` hold all UI strings.
- **Server + client** — `app/layout.tsx` loads messages from `i18n/request.ts` (reads the cookie). Client components use `useTranslations("namespace")`.

## Switch language

Click **EN** or **FR** in the navbar. The choice is remembered in your browser for one year.

## Add or edit translations

1. Add the key to **both** `messages/en.json` and `messages/fr.json`.
2. In a component:

```tsx
"use client";
import { useTranslations } from "next-intl";

export default function MyPage() {
  const t = useTranslations("overview");
  return <h1>{t("title")}</h1>;
}
```

3. For dynamic values: `t("subtitle", { count: 4572 })`.

## Namespaces

| Namespace | Used for |
|-----------|----------|
| `nav` | Navigation tabs |
| `overview` | Home page |
| `models` | AI Models page |
| `predict` | Revenue Forecast |
| `simulator` | Budget Optimizer |
| `targetPlanner` | Target Planner |
| `featureImportance` | Revenue Drivers |
| `insights` | Insights page (if used) |
| `common` | Shared labels (API errors, budget, etc.) |
| `channels` | TV, Radio, Social Media |
| `modelNames` | ML model display names |
| `perfClass` | High / Medium / Low |

## Channel & model labels from API

```tsx
import { channelLabel, modelLabel, perfClassLabel } from "@/lib/i18n-helpers";

const tCh = useTranslations("channels");
channelLabel(tCh, "Social Media"); // → "Réseaux sociaux" in FR

const tm = useTranslations("modelNames");
modelLabel(tm, "random_forest");
```

API responses stay in English; only the **UI** is translated.
